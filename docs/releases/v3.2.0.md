# HaloPixelToolBox v3.2.0

本版接通 DSH 会话与音箱任务链路，并整理项目目录、回归测试和发布流程。普通设备口令复用一个音箱控制会话，开发任务使用独立会话，支持从界面或麦克风继续交互。

## 功能与修复

- **DSH 会话**：聊天气泡、手动输入、历史加载、搜索、重命名及归档/恢复；工具记录、运行上下文和长消息默认折叠。固定设备会话跨重启复用，旧控制记录归集展示，避免每条口令新建会话。
- **音箱任务**：在可配置的默认目录下创建任务目录和会话，监控运行状态并显示到字幕屏；需要回答或授权时播放提示音，界面与麦克风回应同一个请求。设备控制、创建任务和后续任务交互分别路由。
- **语音链路**：本地“花再花再”唤醒与“我在”“收到”提示音；增加灵敏度、指令停顿和最长收音设置，复用模型、麦克风、DSH Host 与设备会话，减少重复启动。失败、超时或连接中断时不自动重发已接受的任务。
- **设备控制**：内置 PixelBar Tool 0.7.0，提供 25 个工具；区分氛围灯效、配色预设与像素场景，支持简繁体、别名、序数和随机选择；接入歌词、自定义字幕、灯速、默认场景与自动关灯配置。
- **画板与灯光**：256×32 自定义画板；电脑熄屏和每日时间段自动关灯，界面状态与外部控制同步。
- **界面**：增大初始窗口，改善窄窗口切换、预览比例、文字重叠和设置展开布局，稳定语音状态提示。

## 开发与验证

- 源码统一放入 `src/`，回归测试放入 `tests/`，外部集成、构建脚本和安装器分别放入 `integrations/`、`eng/`、`packaging/`。
- 新增统一 `eng/Test.ps1` 与 Windows CI；功能、目录迁移和版本记录分开提交，发布版本统一为 3.2.0。
- 全套离线回归通过，包含 694 项断言/检查，以及插件协议与包内容校验；主程序 Release 构建通过。
- 打包校验覆盖插件、会话桥接、语音 Worker 和提示音，拒绝打入本机配置、任务数据、凭据或录音。

## 安装与已知限制

- Windows 10 1809+、x64，需要 .NET 8 Desktop Runtime。提供安装器、便携 ZIP 和 `SHA256SUMS.txt`；安装器尚未代码签名。
- DSH、语音与音效属于开发预览。DSH 可选功能需要本机安装并配置 DeepSeek Harness；本轮验证使用 DSH 0.2.0-rc.2。
- 语音可选功能需要 Python、FunASR、Torch、FFmpeg 和本地模型，模型及个人配置不随发行包分发。当前唤醒采用 ASR 文本匹配，动态朗读回复和专用唤醒模型仍待后续开发。
- 独立音效保留已有预览，仍依赖 Equalizer APO；与 FxSound 对比后，此方向暂缓继续开发，后续路线已写入 README，当前重点为 DSH。

完整配置与兼容说明见 [README](https://github.com/AlexandreShogenji/HaloPixelToolBox/blob/v3.2.0/README.md)。
