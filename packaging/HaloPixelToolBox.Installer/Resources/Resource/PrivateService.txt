HaloPixelToolBox 隐私说明

更新日期：2026 年 9 月 18 日

HaloPixelToolBox 是本地运行的开源桌面工具。项目维护者没有为本软件部署账号、广告、遥测或用户画像服务，也不会通过自有服务器自动收集或出售个人信息。

1. 本地数据

软件会在本机保存运行所需的设置、日志、缓存、ASR 模型、配色方案和自定义场景资源。这些数据不会由软件自动上传到项目维护者的服务器。程序日志可能包含设备状态、功能运行状态、错误信息以及用户主动选择的本地文件路径。

2. 联网功能

只有在使用相应功能时，软件才会直接访问对应的第三方服务：

- 用户在设置页点击“检查 GitHub 更新”时，请求 GitHub Releases API。软件启动时不会自动执行此检查。
- 使用在线歌词、B 站字幕或音频、浏览器字幕及 ASR 模型下载时，请求相应内容提供方或用户配置的下载源。
- 启用腾讯云翻译时，将待翻译的字幕文本发送至用户配置的腾讯云机器翻译接口。
- 播放器同步功能可能读取本机播放器公开的媒体会话、桌面歌词、字幕文件或浏览器调试接口。

上述第三方可能按照各自的隐私政策处理请求所必需的网络信息，例如 IP 地址、请求时间和客户端标识。HaloPixelToolBox 不控制第三方服务的处理方式。

3. 凭据

腾讯云 SecretId 和 SecretKey 由用户主动提供，保存在当前 Windows 用户的环境变量中，用于在本机签名腾讯云请求；软件界面保存后不会回显完整凭据。请勿在日志、截图或问题反馈中公开凭据。

4. 用户控制

用户可以在设置页清除应用缓存和腾讯云凭据，并可打开日志目录与 ASR 模型目录自行管理文件；也可以删除应用数据目录或卸载软件。卸载前请自行备份需要保留的自定义资源。

5. 问题反馈

通过 GitHub Issues 主动提交的日志、截图和文字由用户自行选择，并受 GitHub 的服务与隐私条款约束。提交前请检查其中是否含有文件路径、账号、字幕内容或其他不希望公开的信息。

本说明如有更新，将随软件版本一并发布并保存在公开仓库中。
