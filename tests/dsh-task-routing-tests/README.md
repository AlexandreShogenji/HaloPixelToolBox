# DSH 语音任务路由回归测试

使用 .NET 8 SDK 从仓库根目录运行：

```powershell
dotnet run --project tests/dsh-task-routing-tests/TaskRoutingTests.csproj -c Release
```

项目以相对路径编译真实的 `DshTaskService`、`DshTaskVoiceParser`、`DshVoiceIntentRouter` 和状态模型，使用最小 Profile stub 与假会话客户端，不依赖主 App 的 WinUI 构建。

`PollingProbe` 使用可手动推进的 `TimeProvider` 验证空闲退避：运行和等待互动时每秒刷新，状态未变的空闲/完成任务逐步延长到 15 秒；发送、回答、取消、连接或目标会话状态变化会立即唤醒。覆盖有界错误退避、轮询中收到唤醒、切换/停止取消旧定时器，测试不启动 DSH，也不等待真实的退避时长。

测试覆盖数字和口语创建、明确创建时立即建立空会话、等待正文期间禁止重复创建或提交确认词、低置信任务草稿及自然正文、空闲状态轮询、等待内容状态恢复与远端提交核对、设备控制穿插、没有普通目标时的路由澄清、非创建表达、目录与正文隔离、精确授权和多题回答。假客户端记录请求，不启动 DSH Host、实际任务、ASR、麦克风或设备，也不访问网络。监控身份文件只写入系统临时目录内的独立测试目录。

还覆盖后台断线后重新发现运行中的 Host、接管原会话且不启动服务或重发指令、失败退避与取消、同一请求和完成状态恢复时提示去重、多题交互继续下一题、延迟历史恢复，以及旧恢复不得抢占用户刚建立的任务。未确认接受的消息保持未知状态，配置改变会停止旧监控并清除旧目标。

故障回归包括远端释放失败、超时或离线时仍停止本地监控并移除自动恢复身份，断线和同一状态恢复时静默刷新字幕，以及采用已有任务前等待首份真实状态。互动回复在进入操作队列时绑定会话与完整原请求；同 ID 的问题、选项或授权内容变化、跨任务切换和可变草稿不能复用旧回答，语音多题答案也按完整请求内容隔离。

语音选择回归验证单选与多选序号转换为真实选项标签、歧义和越界不提交、以“回答：”开头的自由答案、重听与检查答案不改变草稿、上一题修改、清空答案不取消真实任务，以及全部答完后仍须明确“确认提交”。缺题、旧请求确认和重复确认不能隐式继续任务。多项授权须先通过序号选定一项并提示详情，再单独批准或拒绝；请求内容改变后原选择失效。

续听断言覆盖新建空任务、下一题、重听、确认前复述等需要继续回答的状态，以及成功提交后结束续听。故障注入还覆盖确认等待操作队列期间请求替换、提交失败后保留草稿且不自动重发。这里只验证服务返回的续听标志和提示文本，不验证音频播放、麦克风回声抑制或字幕屏分页时序；这些分别由语音 Worker 离线测试和实机验收覆盖。

任务列表回归验证仅播报未归档的普通任务、未听过列表时不能按编号选择、同名任务保持歧义、列出后新插入的会话不改变既有编号，以及切换 Profile 后旧编号失效。切换已有任务只释放原监控，不取消真实任务、不新建会话、不重发提示词。

增量操作还验证“修改第 N 题”和跨断线的题目焦点、“加选/加上/取消选择/去掉”对当前或最近多选题的增减、清空多选后重新回答，以及选中的授权请求消失后不得把旧决定应用到剩余请求。语音草稿同步快照保持不可变；重听不改变草稿版本，提交和停止监控后清除发布的草稿状态。

麦克风入口的上下文检查使用播报时保存的快照：旧快照不能批准或拒绝另一个剩余授权，等待操作队列期间请求结构变化也不能记入或提交答案。回归同时核对拒绝旧输入时不会发普通提示词、新建会话或取消任务。

每项输出 `PASS` 或 `FAIL`，出现失败时退出码为 1。HTTP 通道与真实 DSH 兼容性验证不属于这组路由测试。

场景意图回归覆盖“换一个时钟场景”的简繁体与礼貌前缀、ASR“画/换”歧义的本地澄清、已完成任务不得吞下设备口令，以及创建草稿和待填内容时保留绘制任务。真实待答问题中的画/换表达仍是答案，显式音箱控制不会覆盖答案草稿；恢复未监控目标后先读取待答状态。否定、教学和条件句不得因包含时钟场景而误判为设备操作。
